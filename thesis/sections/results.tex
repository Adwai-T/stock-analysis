\section{Overview}

In this chapter I would like to present all the result that I have collected from all the models that were trained for this project. This includes all the chartes and observations that were collected and any interesting observations that I found for any particular models.

I have evaluated multiple machine learning architectures for forcasting next day closing prices of Indian stock market equities trading. The below mentioned models were assessed on both Raw Features as well as on combination of raw and engineered features. Evaluation of these models were done with error metrices and there are a lot of visual graphs that I have included for comparisons.

\section{Training and Validation Behavior}

\begin{itemize}
    \item All models show loss curve decreasing during training.
    \item Confirming the ability to lean patterns in a meaningful way.
    \item How fast they converge depends on the dataset and features included.
    \item Using even basic features like only close data for stocks shows great impact on prediction showing the learning and pattern recognition ability of these models.
\end{itemize}

\section{Single Company Data Used}

Following are the observation that I got from training different models on single company data. These include both with and without indicator features used.

\begin{itemize}
    \item For single-company datasets, \textbf{GRU and LSTM models} converged fastest and most consistently, likely due to their lower parameter count relative to Transformers and CNN-LSTM networks.
    \item When only the \textbf{closing price} was used as the input feature, models fit extremely well and often achieved very low training loss, indicating possible \textbf{overfitting}.
    \item Larger architectures such as \textbf{Transformer and CNN-LSTM} demonstrated slower convergence and required significantly more data to avoid underfitting.
    \item Models like Transformers and CNN-LSTM when used for single company data showed significantly worse performance than simpler algorithm like GRU, LSTM and even classic algorithms like linear regression.
    \item This shows a significant disadvantage in using such algorithms there, when the data-set is smaller.
\end{itemize}

\section{Effect of Feature Engineering vs. Raw OHLCV Inputs}

An important discovery in these experiments is that feature engineering did not always improve model performance.

Key conclusions:

\begin{itemize}
  \item For single-company models, using only Close, Open, High, Low, Volume produced better results than using technical indicators, likely due to overfitting and noise sensitivity introduced by engineered features.
  \item For broader training datasets (NIFTY50, NIFTY200, or all NSE companies), adding indicators improved generalization and reduced error variance.
\end{itemize}

\section{Generalization vs. Specialization Behavior}

\begin{itemize}
  \item GRU and LSTM models that were trained on single company data, specialized very well to that companies prediction, but did lack in generalizing as other companies patterns could not be learnt.
  \item Models trained on larger data set containing many companies generalized extremly well but lacked in capturing the properties and patterns that any particular company's stock might exibit.
  \item Models trained with NIFTY50 and NIFTY200 generalized well enoght to the patterns of the bigger and more stable companies, but lacked when it came to pattern exibited by smaller companies that could be more volatile.
  \item So a tradeoff it observed where smaller company specific models can perform well for that company and largers can capture the market patter overall.
  \item Thus I observed that having models according to the companies segment gives best result for that segment and cannot always be compared to other segments.
  \item This is also try for different industires like Banking, IT, manudacturing and others.
  \item It also means that each country's companies also behave in a different way to global events and how resistant thier market is to external factors.
  \item Thus country specific research is necessary when it comes to training models for that particular country.
\end{itemize}
