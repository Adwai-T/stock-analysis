    \textbf{Abstract}
    
    \vspace{2cm}
\end{center}
Stock price forecasting is a challenging but rewarding problem due to the inherent challenges involved like the volatility, nonlinearity and dynamic nature of financial markets. Stock forecasting might involve trend forecasting or as I explore in this project forecasting based on short term price movement to predict the next day's closing. Traditional Technical analysis and their use in creating forecasting statistical models provide a solid base and robust techniques which could be included in the modern technical analysis using machine learning. Even so the traditional forecasting models lack adaptability to ever changing market behaviour and also are limited by manual capacity to interpret complex temporal patterns. This limitation can be eliminated by using the Machine Learning and deep learning approach for creating sophisticated models that can better understand today's complex market environment. This this project I have applied machine learning and deep learning techniques to predict next day's closing price based on the short-term data.

The last two years of stock data was collected through Kite Connect API for companies listed on NSE. This data is divided into NIFTY50 companies, NIFTY200 companies and the broader NSE universe. Dataset collected from Kite connect API contains Open High Low Close and Volume data. This data then can be pre-processed to calculate additional Technical indicators that indicate market volatility, and trends. Technical Indicators like Relative Strength Index(RSI), On Balance Volumne(OBV), Exponential Moving Average(EMA) and Average True Range (ATR) are calculated and used as additional features that enhance the market movement and help models better learn the patterns.

In this project I have implemented simple models like GRU and LSTM, but also trained larger models with transformers and a hybrid model with CNN-LSTM method. The models are trained with the time-series split to preserve temporal data integrity. The model's performance are assessed with Mean Absolute Error and Root Mean Square Error(RMSE). Implemented code to retrieve data from kite, preprocess the data for training and then show the results according to the model selected. The major findings from the project are smaller models like GRU performed best with limited data, like with single company's historical data. LSTM performed well overall with limited single company as well as multi company data like NIFTY200. Lastly models trained on CNN-LSTM and Transformers needed larger dataset to be trained.
